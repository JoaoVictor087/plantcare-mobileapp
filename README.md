# PlantCare 🌿

**Challenge Sprint - FIAP - 2TDSPA**

Este é o repositório do projeto PlantCare, desenvolvido como parte do Challenge Sprint da FIAP. O PlantCare é um aplicativo móvel projetado para ajudar os usuários a cuidar de suas plantas, oferecendo uma interface simples e intuitiva para monitorar e gerenciar suas necessidades.

## 📜 Sobre o Projeto

O PlantCare nasceu da necessidade de simplificar o cuidado com as plantas para entusiastas de todos os níveis, desde iniciantes até os mais experientes. O aplicativo permite que o usuário cadastre suas plantas e receba informações e lembretes importantes para mantê-las saudáveis e vibrantes.

## ✨ Funcionalidades

- **Autenticação de Usuário**: Sistema de login e cadastro para garantir uma experiência personalizada.
- **Dashboard**: Uma visão geral do estado das suas plantas e das tarefas de cuidado pendentes.
- **Minhas Plantas**: Uma seção dedicada para visualizar e gerenciar todas as plantas cadastradas pelo usuário.
- **Configurações**: Opções para personalizar o perfil e as preferências do aplicativo.

## 🚀 Tecnologias Utilizadas

O projeto foi desenvolvido utilizando as seguintes tecnologias:

- **React Native**: Framework para desenvolvimento de aplicativos móveis multiplataforma.
- **Expo**: Plataforma e conjunto de ferramentas para criar e implantar aplicativos React Native.
- **TypeScript**: Superset do JavaScript que adiciona tipagem estática ao código.
- **Expo Router**: Sistema de roteamento baseado em arquivos para aplicativos Expo.

## ⚙️ Como Executar

Para rodar este projeto localmente, siga os passos abaixo:

### 1. Clone o repositório:

```bash
git clone https://github.com/seu-usuario/seu-repositorio.git
cd seu-repositorio
```

### 2. Instale as dependências:

```bash
npm install
# ou
yarn install
```

### 3. Inicie o projeto:

```bash
npx expo start
```

### 4. Execute no seu dispositivo:

- Faça o download do aplicativo Expo Go na App Store ou Google Play.
- Escaneie o QR code exibido no terminal com o aplicativo Expo Go.
